# 数据说明

本目录只保存说明，不提交体积较大的原始数据集。

- CIFAR-10：可由 `torchvision.datasets.CIFAR10` 自动下载。
- MNIST：Lab3 Notebook 会自动下载。
- Indian Pines：HybridSN Notebook 需要 `Indian_pines_corrected.mat` 和 `Indian_pines_gt.mat`。由于课程示例使用的原始下载地址可能返回 403，建议在 Colab 中手动上传文件，或按照 Notebook 中的可替换路径准备数据。

不要把包含个人密钥的 Kaggle 配置文件、访问令牌或本地绝对路径提交到仓库。
